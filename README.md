Join a creator channel and you get a voice room. Robotnic deletes it when the last person leaves.

## Get started

Add the bot, then run `/setup` in Discord. To run your own copy, follow the
[self-hosting guide](docs/self-hosting.md).

[Docs](docs/README.md) · [Demo](https://jackschultz.dev/Robotnic/#demo) · [Live stats](https://jackschultz.dev/Robotnic/#stats)

> [!NOTE]
> The public bot is free to use. You need **Manage Channels** to run `/setup`.
