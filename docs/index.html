Open-source Discord bot

Temporary voice channels that clean themselves up.

Join a creator channel and Robotnic makes a voice channel for you, posts a control panel in the chat, and deletes the channel when it empties.

staff-logs

Creates, renames, removals, and blocked names show up here.

Servers can show these as icon buttons, icon buttons with labels, or dropdowns, and can turn each action off. This mock uses icons with labels. The staff-logs channel uses the same embeds the bot posts.

    Included on the free bot

    The public bot is free. These are the features other voice bots put behind a paywall. You can also run Robotnic yourself.

    • Unlimited creator channelsIncluded
    • Per-action owner controlsIncluded
    • Activity-based namesIncluded

    • Ban and allow users or rolesIncluded
    • Profanity filter on renamesIncluded
    • Audit logIncluded
    • SQLite, settings survive restartsIncluded
    • No external setup websiteIncluded

    Self-host

    Robotnic is AGPL-3.0. If you run your own instance, the people who use it need access to the source you are running.

    Configuration lives in SQLite. There is no setup website to host.
