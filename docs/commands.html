Commands

Type / in Discord to find a command. For actions on a member, right-click them and choose Apps.

Getting started

Command Who What it does
/setup Manage Channels Create or edit a creator channel.

General

Command Who What it does
/help Everyone List commands and where to get help.
/support, /donate, /website Everyone Get the same support and donation links.
/ping Manage Channels See how long the bot takes to respond.

Server settings

All /settings commands require Manage Channels. The server settings guide explains what you can change.

Command What it does
/settings controls Pick the panel layout, which controls to show and whether to ping the room owner.
/settings logging Pick a channel and decide what goes in the staff log.
/settings profanity_filter Choose off, alert or alert & block for custom room names.
/settings language Change the language Robotnic uses on the server.

Channel owners

Command What it does
/settings owner dm-on-create Choose whether Robotnic DMs new room owners.
/settings owner role-set Pick a role to give to room owners.
/settings owner role-get See which role you’ve set.
/settings owner role-clear Stop giving the role to new owners.
/settings owner prefix-set Set a nickname prefix for room owners.
/settings owner prefix-get See which prefix you’ve set.
/settings owner prefix-clear Stop applying the prefix.

Placeholders

Command What it does
/settings placeholder add Add text that changes with the room owner’s role.
/settings placeholder list List placeholders in a reply only you can see.
/settings placeholder remove Delete a placeholder.

User apps

Action What it does
Ban User from VC Block the member from the room and disconnect them.
Allow User to VC Give the member access to the room.
Mute User Stop the member from speaking in the room.
Deafen User Stop the member from hearing the room.
Unmute & Undeafen User Unmute and undeafen the member at once.
