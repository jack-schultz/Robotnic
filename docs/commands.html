Commands

Members control a temporary voice channel from the panel posted in that channel. Slash commands are for creating creator channels and changing server settings. Type / in Discord and start with the command name.

Getting started Server settings Channel owners Placeholders General User apps

Getting started

/setup

Manage Channels

Opens the creator menu. Use the green Make new Creator button to add a hub, or the dropdown to edit one that already exists. Each creator has its own name template, user limit, category, permission inheritance, and the role that lock and hide apply to. Built-in name tokens are {user}, {activity}, and {count}.

Server settings

/settings controls

Manage Channels

Opens a form for which owner actions appear on the in-channel panel, and whether that panel uses labeled buttons, icon-only buttons, or a dropdown. Submit the form or the change is discarded.

/settings logging

Manage Channels

Opens a form to pick a log channel and which events to record there. Deselect an event to leave it out. Submit the form or the change is discarded.

/settings profanity_filter

Manage Channels

Sets how channel names are checked. The mode option is off, alert (log only), or alert & block (log and reject the name).

Channel owners

/settings owner dm-on-create

Manage Channels

Turns DMs to new channel owners on or off. Pass enabled as true or false.

/settings owner role-set

Manage Channels

Sets the role given to whoever owns a temporary channel. Pass owner_role. The bot needs permission to assign that role.

/settings owner role-get

Manage Channels

Shows the owner role currently configured for this server, or that none is set.

/settings owner role-clear

Manage Channels

Stops assigning an owner role. Existing assignments are left as they are.

/settings owner prefix-set

Manage Channels

Sets a nickname prefix applied while someone owns a temporary channel. Pass owner_prefix. The bot needs Manage Nicknames, and it cannot rename the server owner or members above its highest role.

/settings owner prefix-get

Manage Channels

Shows the owner nickname prefix currently configured for this server, or that none is set.

/settings owner prefix-clear

Manage Channels

Stops applying an owner nickname prefix.

Custom name placeholders

In a creator name template, a token such as {region} is replaced only when the channel owner has the role you attached to that token. If they do not, the token is removed. The same token can map to different text for different roles.

/settings placeholder add

Manage Channels

Opens a form with the placeholder token, the replacement text, and the role required for that replacement. Submit the form or the entry is not saved.

/settings placeholder list

Manage Channels

Lists every custom placeholder on this server, including the replacement text and the role that triggers it. Only you see the reply.

/settings placeholder remove

Manage Channels

Removes one entry. The entry option autocompletes from placeholders already saved on this server.

General

/help

Everyone

Posts a short command list in Discord, with buttons for support and the website.

/donate /support /website

Everyone

The same reply: how to support the public bot, with links to donate and get help. /support and /website are aliases of /donate.

/ping

Manage Channels

Replies with the bot’s current latency.

User apps (right click menu)

Right-click a member, then open Apps. These are the same ban, allow, mute, and deafen actions as the in-channel panel. They apply to the temporary channel you own, or the one you can claim if it has no owner.

Ban User from VC

Channel owner

Blocks that member from your temporary channel and disconnects them if they are in it.

Allow User to VC

Channel owner

Grants that member access to your temporary channel.

Mute User

Channel owner

Server-mutes that member in your temporary channel.

Deafen User

Channel owner

Server-deafens that member in your temporary channel.

Unmute & Undeafen User

Channel owner

Clears both server mute and server deafen for that member. Discord allows five user apps, so unmute and undeafen share this one.
